# skills-pack

Локальная копия четырёх официальных скиллов ZCode, вынесенная из кэша плагинов (`~/.zcode/cli/plugins/cache/zcode-plugins-official/`) в отдельный проект с git-историей.

## Состав

| Каталог | Скилл | Назначение | Источник (версия плагина) |
|---|---|---|---|
| `skills/docx/` | `documents:docx` | Создание/редактирование DOCX: ревизии, комментарии, извлечение текста, конвертация DOCX→PDF→PNG, ГОСТ-подобная вёрстка через docx-js | documents 0.2.1 |
| `skills/docx-viewer/` | `documents:docx-viewer` | Просмотр и обсуждение .docx в боковой панели Documents | documents 0.2.1 |
| `skills/pdf/` | `pdf:pdf` | PDF-производство: отчёты, постеры, академический LaTeX, обработка существующих PDF | pdf 0.2.2 |
| `skills/web-gui-tester/` | `browser-use:web-gui-tester` | GUI-тестирование веб-приложений «как пользователь»: клики, ввод, скриншоты | browser-use 0.5.1 |

Каждый каталог — самодостаточный скилл: `SKILL.md` + вспомогательные файлы (`routes/`, `references/`, `scripts/` и т.п.), лицензия сохранена внутри (`LICENSE.txt`).

## Как подключить как свои скиллы

Вариант 1 — пользовательский скоуп (доступны во всех проектах):

```
cp -r skills/docx ~/.zcode/skills/docx
```

Вариант 2 — проектный скоуп (только в конкретном проекте):

```
cp -r skills/pdf <проект>/.zcode/skills/pdf
```

Учтите: одноимённые скиллы плагинов и пользователя конфликтуют — при загрузке побеждает первый в порядке обнаружения (пользовательский скоуп выше плагинного).

## Обновление из кэша плагинов

При обновлении плагинов ZCode версия в кэше меняется (каталог с новой версией). Актуализировать копию:

```
rsync -a --delete ~/.zcode/cli/plugins/cache/zcode-plugins-official/documents/<новая-версия>/skills/docx/ skills/docx/
```
